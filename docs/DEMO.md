# 演示脚本与发布说明

## 一、逐步点击路径（完整闭环）

### A. 管理端配置（http://localhost:5173）

1. 打开管理端 → 使用 `admin` / `admin123` 登录  
2. **AI面试官 → 面试官设置**：新建人设（名称 + systemPrompt）  
3. **职位管理 → 创建职位**：填写名称/描述/评估 prompt，绑定人设，状态「开启」  
4. **AI面试官 → 面试题库**：为该岗位新增 ≥5 道题（启用）  
5. **候选人管理**：也可直接使用种子账号 `13800000001` / `candidate123`（见 `docs/sql/demo-seed.sql`）

### B. 用户端练习（http://localhost:5174）

1. 候选人登录（如 `13800000001` / `candidate123`）  
2. **上传简历**（可选）→ **简历列表**等到状态 `COMPLETED` → 可看详情评分  
3. **开始面试**：选岗位，可选关联简历 → 开始  
4. 答题页：提交作答 →（可选）生成追问并作答 → 下一题 → 最后「结束面试并评估」  
5. **面试历史**：查看总分、总评、问答；题目来源可见「题库 / LLM补题」  

### C. 管理端验收

1. **面试记录**：列表出现该场面试  
2. 进入详情：候选人、岗位、总分、问答与追问全文  

---

## 二、已知限制

1. 创建面试时若题库不足会同步调用 LLM，首题等待可能较长  
2. 评估/简历分析依赖 Redis Stream 与 AI Key；Key 无效时任务会失败重试至多 3 次  
3. Token 存 Redis，重启 Redis 会导致登录失效（前端会跳转登录）  
4. 无 PDF 导出、无限流、无短信验证码  
5. 前端未做生产构建产物的 Nginx 一键编排（需本地 `npm run dev` 或自行部署 dist）  
6. 旧目录 `ai-interview-guide/`（Maven 脚手架）与业务无关，可忽略
